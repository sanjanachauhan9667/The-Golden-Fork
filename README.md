# 🍴 The Golden Fork

The Golden Fork is a responsive restaurant website created using HTML, CSS, and JavaScript.

The website provides information about the restaurant, its signature dishes, features, customer reviews, and a contact form.


## 🌐 Live Website

Add your GitHub Pages link here after deployment.

## 📌 Features

- Clean and modern restaurant design
- Navigation bar with section links
- Hero section with Book Now button
- Signature Dishes section
- About The Golden Fork section
- Why Choose Us section
- Customer Reviews section
- Contact form
- Form validation using JavaScript
- Email and phone number validation
- Order Now functionality
- Selected dish automatically added to the contact message
- Smooth scrolling
- Footer with social links

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

⚙️ JavaScript Functionality

JavaScript is used to add interactive functionality to the website.

Contact Form Validation

The contact form checks:

Name is not empty
Email is not empty
Email format is valid
Phone number contains 10 digits
Message is not empty
Order Now

When a user clicks an Order Now button:

The selected dish is identified.
The page smoothly scrolls to the contact section.
The selected dish name is automatically added to the message field.
The selected button changes to Selected ✓.
