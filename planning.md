Used for:
- Signature Dishes section background

## 🖥️ Current Responsive Status

The website is currently designed mainly for desktop/laptop screens.

Mobile and tablet responsiveness will be added later using CSS media queries.

## ⚙️ JavaScript Features

- Smooth scrolling from Book Now button
- Order Now button functionality
- Contact form validation
- Email validation
- Phone number validation
- Form reset after successful submission
- Selected dish name added automatically to contact message
